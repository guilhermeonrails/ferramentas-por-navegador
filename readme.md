# Atalhos e Menus - Ferramentas do Desenvolvedor

## Ferramentas do Desenvolvedor por Navegador

| Navegador         | Caminho pelo Menu                                                                                   |
|-------------------|----------------------------------------------------------------------------------------------------|
| Chrome            | Exibir → Desenvolvedor → Ferramentas para desenvolvedores                                          |
| Safari            | Safari → Preferências → Avançado → Marcar “Mostrar menu Desenvolvedor na barra de menus”<br>Depois: Desenvolver → Mostrar inspetor da web |
| Microsoft Edge    | Ferramentas → Desenvolvedor → Ferramentas do desenvolvedor                                         |
| Firefox           | Ferramentas → Ferramentas do navegador → Ferramentas para desenvolvedores web                      |

## Atalhos de Teclado

| Sistema Operacional | Atalho                  |
|----------------------|-------------------------|
| Mac                  | Opção + Comando (⌘) + I |
| Windows              | Ctrl + Shift + I        |
